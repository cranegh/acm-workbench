# Divisibility：从暴力到奇偶分层 BFS

> 这份题解重在说明“怎么一步一步想到正解”，而不是直接堆结论。
>
> 全文使用纯文本公式，方便在终端中阅读。

---

## 1. 我们到底要求什么？

对于每个点 `u`，要找最小的非负整数 `d`，满足：

```text
1. d 是 k 的倍数
2. 存在一条从 1 到 u、长度恰好为 d 的路线
```

题目允许路线重复经过点和边。

因此，这里不是通常所说的“不重复顶点的简单路径”，而是可以来回绕路的路线。

这个条件非常重要，因为它意味着：

```text
到达 u 以后，我们可能通过绕路来增加路线长度。
```

另外，从点 `1` 到点 `1` 可以一条边都不走，所以：

```text
f(1) = 0
```

---

## 2. 第一反应：把“长度模 k”放进 BFS 状态

因为题目要求最终长度能被 `k` 整除，一个直接想法是记录：

```text
当前在哪个点 + 当前长度除以 k 的余数
```

也就是建立状态：

```text
(u, r)
```

含义是：

```text
当前位于 u，已经走过的长度 % k = r
```

经过一条边后，长度增加 `1`，于是：

```text
(u, r) -> (v, (r + 1) % k)
```

从 `(1, 0)` 开始 BFS，第一次到达 `(u, 0)` 的距离似乎就是答案。

### 这个模型为什么不能用？

状态数量大约是：

```text
n * k
```

而题目中：

```text
n <= 5 * 10^5
k <= 10^9
```

`k` 太大了，不可能维护所有余数。

所以我们要继续思考：

```text
题目中的“无向图”和“允许重复走边”能不能帮我们压缩状态？
```

---

## 3. 无向图中，可以让路线长度增加 2

假设一条从点 `1` 到点 `u` 的路线中经过了无向边：

```text
x -- y
```

走到 `x` 时，我们可以先额外走一圈：

```text
x -> y -> x
```

然后再按照原路线继续前进。

这次操作：

```text
起点没有改变
终点没有改变
路线长度增加 2
```

而且可以重复任意多次。

因此，如果长度 `L` 能够到达点 `u`，那么下面这些长度也都能够到达：

```text
L
L + 2
L + 4
L + 6
...
```

这一步是整道题最重要的突破口。

---

## 4. 这个性质告诉了我们什么？

增加 `2` 不会改变奇偶性。

所以，如果已经找到一条长度为偶数的路线，我们可以把它扩展成更长的偶数路线；如果找到一条长度为奇数的路线，也可以把它扩展成更长的奇数路线。

也就是说，对于同一个点 `u`：

```text
知道最短偶数路线后，所有更长的偶数长度都可以构造出来。
知道最短奇数路线后，所有更长的奇数长度都可以构造出来。
```

于是我们不再需要记录完整的：

```text
长度 % k
```

只需要记录：

```text
长度 % 2
```

原本可能有 `k` 种余数，现在只剩下两种状态：

```text
偶数
奇数
```

---

## 5. 为什么不能只求普通最短距离？

你可能会想：

```text
先求点 1 到点 u 的普通最短距离，再向上取整到 k 的倍数，不行吗？
```

不行，因为向上取整可能改变奇偶性，而我们每次绕路只能增加 `2`。

例如图中只有一条边：

```text
1 -- 2
```

从点 `1` 到点 `2` 可以得到的路线长度是：

```text
1：1 -> 2
3：1 -> 2 -> 1 -> 2
5：1 -> 2 -> 1 -> 2 -> 1 -> 2
...
```

所有可行长度都是奇数，不可能得到长度 `2`。

如果 `k = 2`：

```text
普通最短距离 = 1
不小于 1 的最小 2 的倍数 = 2
```

但长度 `2` 实际上不可行。

问题就在于：

```text
最短距离 1 是奇数，而 2 是偶数。
二者之差为 1，无法通过若干次“增加 2”得到。
```

所以普通最短距离包含的信息不够。

我们必须分别求：

```text
dist[u][0]：从 1 到 u 的最短偶数路线长度
dist[u][1]：从 1 到 u 的最短奇数路线长度
```

---

## 6. 怎样求“最短偶数距离”和“最短奇数距离”？

把每个原图顶点 `u` 拆成两个状态：

```text
(u, 0)：以偶数长度到达 u
(u, 1)：以奇数长度到达 u
```

经过一条边，路线长度增加 `1`，所以奇偶性一定翻转：

```text
(u, 0) --走一条边--> (v, 1)
(u, 1) --走一条边--> (v, 0)
```

起点是：

```text
(1, 0)
```

因为一开始位于点 `1`，走过的边数是 `0`，属于偶数。

然后在这个“两层状态图”上进行 BFS。

### BFS 状态转移

当我们取出状态：

```text
(u, parity)
```

并沿原图中的边走向 `v` 时，新状态就是：

```text
(v, parity ^ 1)
```

其中 `^ 1` 表示翻转奇偶性：

```text
0 ^ 1 = 1
1 ^ 1 = 0
```

### BFS 结束后得到什么？

```text
dist[u][0] = 到达 u 的最短偶数长度
dist[u][1] = 到达 u 的最短奇数长度
```

如果某个状态不可达，就记为 `-1`。

---

## 7. 可以怎样理解这两层状态图？

假设原图中有边：

```text
u -- v
```

两层状态图中的连接关系是：

```text
偶数层的 u <-> 奇数层的 v
奇数层的 u <-> 偶数层的 v
```

可以想象成：

```text
偶数层： (1,0) (2,0) (3,0) ...
             \     \     \
              原图的边跨层连接
             /     /     /
奇数层： (1,1) (2,1) (3,1) ...
```

每走一步就在上下两层之间切换一次。

原图有 `n` 个点，分层以后只有 `2*n` 个状态，所以 BFS 完全可行。

---

## 8. 为什么有些点只有一种奇偶距离？

在二分图中，从固定起点到某个点的所有路线长度奇偶性相同。

例如：

```text
1 -- 2 -- 3
```

从 `1` 到 `2` 只能得到奇数长度，从 `1` 到 `3` 只能得到偶数长度。

因此可能出现：

```text
dist[2][0] = -1
dist[2][1] = 1
```

如果连通块中存在奇环或自环，就可能同时以奇数和偶数长度到达同一个点，因此两个状态都可能可达。

这也解释了为什么必须真的对两个奇偶状态做 BFS，而不能只看普通最短路的奇偶性。

---

## 9. 求出 dist 后，还差最后一步

现在已经知道：

```text
dist[u][0]：最短偶数长度
dist[u][1]：最短奇数长度
```

接下来，对于每个可达状态，我们要寻找：

```text
不小于 dist[u][parity] 的最小 k 的倍数
并且这个倍数的奇偶性必须等于 parity
```

为什么要保证奇偶性相同？

假设：

```text
D = dist[u][parity]
candidate = 某个 k 的倍数
```

我们要通过不断增加 `2`，把长度从 `D` 变成 `candidate`。

因此必须满足：

```text
candidate >= D
candidate - D 是偶数
```

第二个条件等价于：

```text
candidate 和 D 奇偶性相同
```

只要这两个条件成立，就可以构造出长度恰好为 `candidate` 的路线。

---

## 10. 先看 k 是偶数的情况

如果 `k` 是偶数，那么它的所有倍数都是偶数：

```text
0, k, 2*k, 3*k, ...
```

所以最终答案不可能是奇数，只需要考虑：

```text
dist[u][0]
```

如果 `dist[u][0] == -1`，说明无法以偶数长度到达点 `u`，那么也就不可能以 `k` 的倍数到达，答案为 `-1`。

否则，令：

```text
D = dist[u][0]
```

不小于 `D` 的最小 `k` 的倍数可以这样求：

```text
cnt = (D + k - 1) / k
candidate = cnt * k
```

因为 `k` 是偶数，所以 `candidate` 一定是偶数。

而 `D` 也是偶数，因此：

```text
candidate - D 是非负偶数
```

所以可以通过绕路把 `D` 增加到 `candidate`。

---

## 11. 再看 k 是奇数的情况

如果 `k` 是奇数，那么：

```text
cnt * k 的奇偶性与 cnt 相同
```

例如 `k = 5`：

```text
0 * 5 = 0    偶数
1 * 5 = 5    奇数
2 * 5 = 10   偶数
3 * 5 = 15   奇数
```

因此：

```text
如果要得到偶数倍数，就让 cnt 为偶数。
如果要得到奇数倍数，就让 cnt 为奇数。
```

对于一个可达的奇偶状态 `parity`，令：

```text
D = dist[u][parity]
```

首先找到不小于 `D` 的第一个 `k` 的倍数：

```text
cnt = (D + k - 1) / k
```

但是这个倍数的奇偶性不一定正确。

由于 `k` 是奇数，`cnt*k` 的奇偶性就是 `cnt` 的奇偶性。因此检查：

```text
cnt % 2 是否等于 parity
```

如果不相等，就执行：

```text
cnt++
```

相邻两个整数奇偶性相反，所以加 `1` 后一定满足要求。

最后得到候选答案：

```text
candidate = cnt * k
```

分别用 `dist[u][0]` 和 `dist[u][1]` 计算候选答案，再取最小值即可。

## 12. 用一个例子走完整个过程

假设某个点 `u` 的 BFS 结果是：

```text
dist[u][0] = 8
dist[u][1] = 3
k = 5
```

因为 `k = 5` 是奇数，所以两个奇偶状态都要考虑。

### 从最短偶数距离 8 出发

先找不小于 `8` 的第一个 `5` 的倍数：

```text
cnt = (8 + 5 - 1) / 5
    = 12 / 5
    = 2
```

`cnt = 2` 是偶数，符合当前的偶数状态。

所以：

```text
candidate_even = 2 * 5 = 10
```

从长度 `8` 的路线出发，额外往返一次，长度增加 `2`，就能得到长度 `10`。

### 从最短奇数距离 3 出发

先找不小于 `3` 的第一个 `5` 的倍数：

```text
cnt = (3 + 5 - 1) / 5
    = 7 / 5
    = 1
```

`cnt = 1` 是奇数，符合当前的奇数状态。

所以：

```text
candidate_odd = 1 * 5 = 5
```

从长度 `3` 的路线出发，额外往返一次，长度增加 `2`，就能得到长度 `5`。

最终答案是：

```text
min(10, 5) = 5
```

## 13. 再看一个需要修正 cnt 奇偶性的例子

假设：

```text
D = 7
parity = 1
k = 3
```

我们需要找一个不小于 `7` 的奇数长度，并且它还是 `3` 的倍数。

先向上取整：

```text
cnt = (7 + 3 - 1) / 3
    = 9 / 3
    = 3
```

`cnt = 3` 是奇数，符合 `parity = 1`，所以：

```text
candidate = 3 * 3 = 9
```

`9 - 7 = 2`，可以通过一次往返补出来。

现在换成：

```text
D = 8
parity = 0
k = 3
```

向上取整仍然得到：

```text
cnt = 3
candidate = 9
```

但是 `9` 是奇数，而 `D = 8` 是偶数。

不能通过不断增加 `2`，把 `8` 变成 `9`。

所以要令：

```text
cnt++
cnt = 4
candidate = 4 * 3 = 12
```

现在：

```text
12 - 8 = 4
```

可以通过两次往返补出来，因此 `12` 才是这个偶数状态产生的最小合法候选答案。

## 14. 思路压缩成四句话

如果需要在比赛中快速回忆，可以记住下面四句话：

```text
1. 直接记录长度模 k，需要 n*k 个状态，k 太大。
2. 无向边可以来回走一次，使路线长度增加 2。
3. 所以只需记录长度奇偶性，用两层图 BFS 求 dist[u][0/1]。
4. 对每个奇偶状态，寻找不小于 dist 的、奇偶性相同的最小 k 的倍数。
```

---

## 15. 伪代码

```text
读入图

把 dist 的所有状态初始化为 -1
dist[1][0] = 0
将 (1, 0) 放入 BFS 队列

while 队列非空:
    取出 (u, parity)

    for u 的每个邻点 v:
        nextParity = parity ^ 1

        if dist[v][nextParity] == -1:
            dist[v][nextParity] = dist[u][parity] + 1
            把 (v, nextParity) 加入队列

for 每个点 u:
    answer = 无穷大

    if k 是偶数:
        只考虑 dist[u][0]

        if dist[u][0] 可达:
            cnt = 向上取整(dist[u][0] / k)
            answer = cnt * k

    else:
        for parity = 0, 1:
            if dist[u][parity] 不可达:
                continue

            D = dist[u][parity]
            cnt = 向上取整(D / k)

            if cnt 的奇偶性不等于 parity:
                cnt++

            answer = min(answer, cnt * k)

    如果 answer 仍为无穷大:
        输出 -1
    否则:
        输出 answer
```

## 16. 完整 C++ 实现

```cpp
#include <bits/stdc++.h>

using namespace std;
using ll = long long;

void solve()
{
    int n, m;
    ll k;
    cin >> n >> m >> k;

    vector<vector<int>> graph(n + 1);

    for (int i = 0; i < m; ++i)
    {
        int u, v;
        cin >> u >> v;

        graph[u].push_back(v);
        graph[v].push_back(u);
    }

    // dist[u][0]：到达 u 的最短偶数长度
    // dist[u][1]：到达 u 的最短奇数长度
    vector<array<int, 2>> dist(n + 1, array<int, 2>{-1, -1});

    queue<pair<int, int>> q;
    dist[1][0] = 0;
    q.push({1, 0});

    while (!q.empty())
    {
        auto [u, parity] = q.front();
        q.pop();

        for (int v : graph[u])
        {
            int nextParity = parity ^ 1;

            if (dist[v][nextParity] == -1)
            {
                dist[v][nextParity] = dist[u][parity] + 1;
                q.push({v, nextParity});
            }
        }
    }

    for (int u = 1; u <= n; ++u)
    {
        ll answer = LLONG_MAX;

        if (k % 2 == 0)
        {
            // k 的所有倍数都是偶数，因此只考虑偶数状态。
            if (dist[u][0] != -1)
            {
                ll d = dist[u][0];
                ll cnt = (d + k - 1) / k;
                answer = cnt * k;
            }
        }
        else
        {
            // k 为奇数时，cnt*k 和 cnt 的奇偶性相同。
            for (int parity = 0; parity < 2; ++parity)
            {
                if (dist[u][parity] == -1)
                    continue;

                ll d = dist[u][parity];
                ll cnt = (d + k - 1) / k;

                if ((cnt & 1LL) != parity)
                    ++cnt;

                answer = min(answer, cnt * k);
            }
        }

        if (answer == LLONG_MAX)
            cout << -1;
        else
            cout << answer;

        cout << " \n"[u == n];
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    while (T--)
        solve();

    return 0;
}
```

## 17. 正确性中最需要确认的地方

### 为什么“同奇偶且更长”就一定可以到达？

设某条已知路线长度为 `D`，目标长度为 `L`。

如果：

```text
L >= D
L 与 D 奇偶性相同
```

那么：

```text
L - D
```

一定是非负偶数，可以写成：

```text
L - D = 2 * x
```

在原路线中的某条无向边上往返 `x` 次，每次增加 `2`，就能把总长度变成 `L`。

唯一需要留意的是长度为 `0` 的空路线没有经过边。但这只影响起点 `1`，而起点已经直接拥有最优答案 `0`，不需要再增加长度来获得更优解。

### 为什么只记录奇偶性不会漏解？

任意路线长度不是偶数就是奇数。

对于每种奇偶性，我们保留该奇偶性下的最短长度。所有更长且同奇偶的长度都能通过增加 `2` 构造出来，所以更长的路线不会提供额外信息。

因此每个点只保留两个最短距离已经足够。

## 18. 复杂度

每个原图顶点被拆成两个状态，因此状态数是：

```text
2 * n
```

每条边只会在两个奇偶状态下被检查常数次，所以：

```text
时间复杂度：O(n + m)
空间复杂度：O(n + m)
```

---

## 19. 最终要掌握的核心

这道题表面上是在问：

```text
如何让路线长度模 k 等于 0？
```

但由于 `k` 可以达到 `10^9`，显然不能真的维护模 `k` 的状态。

真正的突破来自无向图中的往返操作：

```text
走过去再走回来，长度增加 2，位置不变。
```

所以一条路线能够自由扩展的范围不是所有更大长度，而是：

```text
所有更大且奇偶性相同的长度。
```

因此问题从“维护 k 种余数”被压缩成了“维护 2 种奇偶状态”，最终得到：

```text
奇偶分层图 BFS + 寻找奇偶性正确的最小 k 的倍数
```
