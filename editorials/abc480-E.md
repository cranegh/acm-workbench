# ABC480 E - Product-Bounded Arithmetic Sequences 题解

[原题链接](https://atcoder.jp/contests/abc480/tasks/abc480_e)

题目要求统计长度至少为 3、公差为正整数、所有项的乘积不超过 $n$ 的正整数等差数列，$1\le n\le 10^{18}$。

## 先把三个量分开

一个等差数列由首项 `a`、长度 `k` 和公差 `d` 唯一确定。直接枚举这三个量，公差的范围会很大。

但首项和长度其实都不大。

- 至少有三项，而且每项都不小于 `a`，所以必须有 $a^3\le n$。首项只需要枚举到 $\lfloor\sqrt[3]{n}\rfloor$，最大是 $10^6$。
- 首项和公差都至少是 1，所以第 $i$ 项至少是 $i$，长度为 `k` 的乘积至少是 $k!$。$19!\le10^{18}<20!$，因此合法长度最多是 19。

代码中 `k` 枚举到 20 也没问题：这一轮一定不合法，会在 `check(a,k,1)` 处退出。

## 固定 a 和 k，二分 d

首项和长度确定后，公差越大，后面的项就越大，乘积也越大。

因此合法公差一定是一段连续的整数：

$$
1,2,\ldots,d_{\max}
$$

找出最后一个合法公差，就能直接给答案加上 `d_max`，不用一个一个枚举。

二分前先判断最小公差 1：

```cpp
if(!check(a,k,1)) break;
```

如果连公差 1 都不合法，更大的公差也不会合法。继续增加长度只会乘上更多正整数，所以当前首项对应的更长数列也可以全部跳过。这就是这里能够 `break`，而不只是 `continue` 的原因。

二分的 `l = 0` 是表示“还没有合法正公差”的哨兵，不会作为真实公差传给 `check`。前三项的乘积满足

$$
a(a+d)(a+2d)\ge(1+d)(1+2d)>2d^2,
$$

所以合法公差一定小于 $\sqrt{n/2}$。原代码用 `pow(1.0*n/2,1.0/2)+1` 设置右侧上界，在这个区间内二分即可。

```cpp
while(l+1!=r){
    ll d = (l+r)/2;
    if(check(a,k,d)) l = d;
    else r = d;
}
ans += l;
```

每个数列只对应一组 `(a,k,d)`，按首项和长度分别累加，不会重复计算。

## 乘积太大，就反过来除

判断乘积是否超过 $n$ 时，即使最后发现不合法，中途的乘法也可能已经让 `long long` 溢出。

原实现没有计算乘积，而是从 `n` 开始依次整除每一项：

```cpp
bool check(ll a, ll k, ll d){
    ll res = n;
    for(ll i=1; i<=k; i++){
        res /= a+(i-1)*d;
        if(res == 0) return false;
    }
    return true;
}
```

对于正整数 $x,y$，有

$$
\left\lfloor\frac{\lfloor n/x\rfloor}{y}\right\rfloor
=\left\lfloor\frac{n}{xy}\right\rfloor.
$$

因此连续整除结束后，`res` 就是 $n$ 除以整个乘积的向下取整。结果至少为 1，恰好表示乘积不超过 $n$；结果为 0，就可以立刻返回。

这里的前提是所有因子都是正整数。判定过程没有做乘积，避免了乘积本身的溢出。

## 复杂度与边界

设首项上界为 $A=\lfloor\sqrt[3]{n}\rfloor$，长度枚举上界为 $K=20$。每次 `check` 最多做 $k$ 次整除，每次二分做 $O(\log n)$ 次判定。一个宽松的时间上界是

$$
O(AK^2\log n),
$$

额外空间为 $O(1)$。实际枚举会提前退出：对于固定长度 $k$，只有 $a^k\le n$ 的首项可能进入二分，长度越大，首项范围越小。不能把一次 `check` 当作与长度无关的操作来漏掉这部分开销。

最小合法数列是 $(1,2,3)$，所以 $n<6$ 时答案为 0。答案按原题保证不超过 $10^{18}$，使用 `long long` 保存。
