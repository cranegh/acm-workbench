# Divisibility —— 奇偶分层图 BFS

> 本题解不使用 LaTeX，所有公式都写成终端可以直接阅读的纯文本形式。

## 一、题意翻译

给定一张无向图，允许有重边和自环。

对于每个点 `u`，我们要找到最小的非负整数 `d`，使得：

1. `d` 是 `k` 的倍数；
2. 存在一条从点 `1` 到点 `u`、长度恰好为 `d` 的路线。

这里的路线允许重复经过同一个点或同一条边。

如果不存在这样的 `d`，输出 `-1`。

特别地，从点 `1` 到点 `1` 可以什么都不走，路线长度为 `0`，而 `0` 是任意正整数 `k` 的倍数，所以：

```text
f(1) = 0
```

---

## 二、为什么不能直接维护“长度除以 k 的余数”？

一个很自然的想法是把 BFS 状态写成：

```text
(u, r)
```

其中：

- `u` 表示当前位于哪个点；
- `r` 表示当前路线长度除以 `k` 的余数。

每经过一条边，状态从：

```text
(u, r)
```

变成：

```text
(v, (r + 1) % k)
```

但是这种做法一共有大约 `n * k` 个状态。

题目中：

```text
n <= 5 * 10^5
k <= 10^9
```

`n * k` 完全无法接受，因此必须继续利用“无向图”这个性质。

---

## 三、最关键的观察：路线长度可以增加 2

假设我们已经找到一条从点 `1` 到点 `u` 的路线，长度是 `L`。

因为图是无向图，所以当我们经过一条边 `x -- y` 时，可以额外这样走：

```text
x -> y -> x
```

这次绕路：

- 最后仍然回到 `x`；
- 不会改变最终要到达的点；
- 路线长度增加了 `2`。

这个操作可以重复任意多次。因此，只要长度 `L` 可以到达点 `u`，那么下面这些长度也都可以到达：

```text
L, L + 2, L + 4, L + 6, ...
```

所以我们真正需要关心的不是“长度除以 k 的余数”，而只是：

```text
路线长度是偶数还是奇数
```

---

## 四、为什么普通最短路不够？

考虑下面这张图：

```text
1 -- 2
```

从点 `1` 到点 `2` 可以走出的长度为：

```text
1, 3, 5, 7, ...
```

例如：

```text
长度 1：1 -> 2
长度 3：1 -> 2 -> 1 -> 2
长度 5：1 -> 2 -> 1 -> 2 -> 1 -> 2
```

不存在长度为 `2` 的路线。

假设 `k = 2`，普通最短距离是 `1`。如果直接把 `1` 向上取整到 `2` 的倍数，会得到 `2`，但长度为 `2` 的路线实际上不存在。

因此，我们需要分别求出：

```text
dist[u][0]：从点 1 到点 u 的最短偶数长度
dist[u][1]：从点 1 到点 u 的最短奇数长度
```

---

## 五、建立奇偶分层图

对于原图中的每个点 `u`，建立两个状态：

```text
(u, 0)：走了偶数条边后到达 u
(u, 1)：走了奇数条边后到达 u
```

每经过一条边，路线长度增加 `1`，所以奇偶性一定翻转。

也就是说，原图中的无向边：

```text
u -- v
```

在状态图中产生下面的转移：

```text
(u, 0) -> (v, 1)
(u, 1) -> (v, 0)
(v, 0) -> (u, 1)
(v, 1) -> (u, 0)
```

初始时位于点 `1`，并且一条边都没有走，所以起点状态是：

```text
(1, 0)
```

从 `(1, 0)` 开始进行普通 BFS，就能计算所有 `dist[u][0]` 和 `dist[u][1]`。

状态总数只有 `2 * n`，所以这一步是线性的。

### 自环是否需要特殊处理？

不需要。

经过一次自环也会让路线长度增加 `1`，所以奇偶性正常翻转。例如点 `u` 有自环时，可以从：

```text
(u, 0)
```

走到：

```text
(u, 1)
```

代码按照普通边处理即可。

## 六、已知最短奇偶距离后，怎样计算答案？

假设我们现在考虑奇偶性 `p`：

```text
p = 0 表示偶数
p = 1 表示奇数
```

并且：

```text
D = dist[u][p]
```

我们要寻找最小的 `k` 的倍数 `answer`，满足：

```text
answer >= D
answer 和 D 的奇偶性相同
```

为什么满足这两个条件就可以？

因为 `answer - D` 是一个非负偶数，所以可以在最短路线中加入若干次“沿一条边走过去再走回来”，把路线长度从 `D` 增加到 `answer`。

接下来根据 `k` 的奇偶性分类讨论。

---

## 七、情况一：k 是偶数

当 `k` 是偶数时，它的所有倍数都是偶数：

```text
0, k, 2*k, 3*k, ...
```

因此，最终答案一定是偶数，只需要使用：

```text
dist[u][0]
```

如果 `dist[u][0] == -1`，说明不存在偶数长度的路线，答案就是 `-1`。

否则，先计算不小于 `dist[u][0]` 的最小倍数：

```text
cnt = (dist[u][0] + k - 1) / k
answer = cnt * k
```

这里使用的是整数除法。

由于 `k` 是偶数，`answer` 自然也是偶数，所以它和 `dist[u][0]` 的奇偶性相同。

---

## 八、情况二：k 是奇数

当 `k` 是奇数时：

```text
cnt * k 的奇偶性 = cnt 的奇偶性
```

例如 `k = 3`：

```text
0 * 3 = 0   偶数
1 * 3 = 3   奇数
2 * 3 = 6   偶数
3 * 3 = 9   奇数
```

所以：

- 使用偶数距离 `dist[u][0]` 时，需要让 `cnt` 为偶数；
- 使用奇数距离 `dist[u][1]` 时，需要让 `cnt` 为奇数。

对于每一种可达的奇偶状态，先计算：

```text
cnt = (D + k - 1) / k
```

这表示先找到不小于 `D` 的第一个 `k` 的倍数。

如果 `cnt` 的奇偶性不等于 `p`，就执行：

```text
cnt++
```

此时：

```text
candidate = cnt * k
```

就是当前奇偶状态可以产生的最小答案。

最后在偶数状态和奇数状态产生的候选答案中取较小值。

## 九、手算一个例子

假设：

```text
k = 5
dist[u][0] = 8
dist[u][1] = 3
```

### 使用偶数距离 8

先找不小于 `8` 的最小 `5` 的倍数：

```text
cnt = (8 + 5 - 1) / 5 = 2
candidate = 2 * 5 = 10
```

`cnt = 2` 是偶数，因此 `candidate = 10` 也是偶数，和距离 `8` 的奇偶性相同。

所以 `10` 合法。

### 使用奇数距离 3

先找不小于 `3` 的最小 `5` 的倍数：

```text
cnt = (3 + 5 - 1) / 5 = 1
candidate = 1 * 5 = 5
```

`cnt = 1` 是奇数，因此 `candidate = 5` 也是奇数，和距离 `3` 的奇偶性相同。

所以 `5` 合法。

最终取较小值：

```text
answer = min(10, 5) = 5
```

## 十、正确性说明

### 结论 1：BFS 求出的距离正确

状态 `(u, p)` 表示以奇偶性 `p` 的长度到达点 `u`。

每经过一条边，奇偶性翻转，所以状态转移与真实行走过程完全一致。

所有边的代价都是 `1`，因此从 `(1, 0)` 开始 BFS，得到的 `dist[u][p]` 就是以奇偶性 `p` 到达 `u` 的最短长度。

### 结论 2：算法产生的候选答案一定可达

对于某个可达状态，设最短长度是 `D`。

算法选择的候选答案满足：

```text
candidate >= D
candidate 与 D 奇偶性相同
```

所以：

```text
candidate - D
```

一定是非负偶数。

通过反复进行“沿无向边走过去再走回来”的操作，每次增加 `2`，可以把长度从 `D` 增加到 `candidate`。

因此该候选答案一定真实可达。

### 结论 3：算法得到的是最小答案

任何合法答案都属于偶数长度或奇数长度中的一种。

对于该奇偶性，BFS 求出的 `D` 不会大于这个合法答案。算法又选择了不小于 `D`、奇偶性正确的最小 `k` 的倍数，所以算法产生的候选值不会比真正的最优答案更大。

同时，根据结论 2，算法产生的候选值本身又是合法的。

因此算法得到的就是最小合法答案。

## 十一、完整 C++ 代码

```cpp
#include <bits/stdc++.h>

using namespace std;
using ll = long long;

void solve()
{
    int n, m;
    ll k;
    cin >> n >> m >> k;

    vector<vector<int>> graph(n + 1);

    for (int i = 0; i < m; ++i)
    {
        int u, v;
        cin >> u >> v;

        graph[u].push_back(v);
        graph[v].push_back(u);
    }

    // dist[u][0]：到达 u 的最短偶数长度
    // dist[u][1]：到达 u 的最短奇数长度
    vector<array<int, 2>> dist(n + 1, array<int, 2>{-1, -1});

    queue<pair<int, int>> q;
    dist[1][0] = 0;
    q.push({1, 0});

    while (!q.empty())
    {
        auto [u, parity] = q.front();
        q.pop();

        for (int v : graph[u])
        {
            int nextParity = parity ^ 1;

            if (dist[v][nextParity] == -1)
            {
                dist[v][nextParity] = dist[u][parity] + 1;
                q.push({v, nextParity});
            }
        }
    }

    for (int u = 1; u <= n; ++u)
    {
        ll answer = LLONG_MAX;

        if (k % 2 == 0)
        {
            // k 为偶数时，k 的倍数一定是偶数。
            if (dist[u][0] != -1)
            {
                ll d = dist[u][0];
                ll cnt = (d + k - 1) / k;
                answer = cnt * k;
            }
        }
        else
        {
            // k 为奇数时，cnt*k 与 cnt 的奇偶性相同。
            for (int parity = 0; parity < 2; ++parity)
            {
                if (dist[u][parity] == -1)
                    continue;

                ll d = dist[u][parity];
                ll cnt = (d + k - 1) / k;

                // 保证 cnt*k 与 d 的奇偶性相同。
                if ((cnt & 1LL) != parity)
                    ++cnt;

                answer = min(answer, cnt * k);
            }
        }

        if (answer == LLONG_MAX)
            cout << -1;
        else
            cout << answer;

        cout << " \n"[u == n];
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    while (T--)
        solve();

    return 0;
}
```

## 十二、复杂度分析

奇偶分层图中，每个原图顶点只有两个状态。

每个状态最多访问一次，每条边只会被常数次检查，因此：

```text
时间复杂度：O(n + m)
空间复杂度：O(n + m)
```

题目保证所有测试数据的 `n` 之和与 `m` 之和都不超过 `5 * 10^5`，所以可以通过。

---

## 十三、最应该记住的思维套路

当题目同时出现下面几个条件时：

- 无向图；
- 允许重复经过点和边；
- 对路线长度有整除或取模要求；
- 模数很大，无法建立 `n * k` 个状态；

要优先想到：

```text
沿无向边走过去再走回来，可以让路线长度增加 2。
```

于是很多看似需要维护“长度模 k”的问题，实际上只需要维护“长度的奇偶性”。

本题最终使用的就是：

```text
奇偶分层图 + BFS
```
